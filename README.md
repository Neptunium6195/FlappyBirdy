The classic Flappy Bird Game that uses the space bar to go up, a random method to randomize the heights of the pipes and
a gravity and velocity system for jumps.
It also has a play again button and a lose screen with a score board.
To start press space, to jump, also press space.

This was madde all in Java and uses the Java swing framework for the GUI.
